# 游戏性优化计划（插在第 10 步之前）

状态：**待开工**（用量重置后开始）。来源：作者 2026-11-16 的反馈——「目前的游戏还太无趣」。

## 作者给的方向

### 1. 构筑深度：升级要改「机制」，不只是改「数值」
- **普通**奖励给数值，但要有取舍（射速 +30% 但单发 -15%；散射变宽但射程变短）
- **稀有**奖励改机制（反弹一次、命中分裂、穿透、滞留成地雷、击杀回血但最大血量锁定）
- **史诗**奖励改规则（不能主动射击，只能反弹敌弹；血量为 1 但擦弹无敌帧翻倍）
- 先设计好几个明确的构筑原型，让随机池围绕它们转，不要大锅乱炖：
  - **擦弹流**：擦弹攒资源、充能、触发特效（作为核心系统，不是点缀）
  - **BOMB 流**：数量、范围、清屏后掉落，鼓励「憋大放小」
  - **使魔/子机流**：输出重心移到可部署单位，玩家专注走位
  - **低速精密流**：低速模式收益翻倍，奖励贴脸微操
  - **符卡爆发流**：攒条放大招，围绕充能速度和大招形态
- 参考 Hades：局内强化几乎都是「改变武器某一部分的行为」，所以每局手感真的不同

### 2. 敌人和弹幕是「出题人」
- 不同弹幕是不同的谜题：密集米弹考微操，狙弹考诱导走位，滞留弹考空间管理
- 某些构筑对某类弹幕天然好打/难打（追踪不怕乱窜的敌人，但打站桩厚血 Boss 疲软）
- Boss 符卡阶段化：一张符卡一个主题，既是演出也是考试
- 目标：选路线时想的是「我这把的构筑怕不怕那个 Boss」

### 3. 重开钩子
- **机体即角色**：灵梦追踪、魔理沙直线炮、咲夜时停……每个机体有专属升级池
- **局外成长要克制**：解锁新机体、新符卡、新起始构筑可以；纯数值加成要谨慎
- **死亡归因要清晰**：不能有无解弹幕；构筑强度方差不能大到「开局就注定输」
- **单局 20～40 分钟**
- 利用「差一点点」：符卡阶段化带来的「就差最后一管血」

### 4. 第一件事：做一个完整的流派闭环来验证手感
**擦弹充能 → 充能换爆发 → 爆发清屏 → 清屏掉资源 → 资源强化擦弹收益**
把这条链打磨爽，再配 2～3 个和它有化学反应的通用升级。

## 开工时的初步拆解（待作者确认）

1. **擦弹升格为核心资源**
   - 擦弹连击计数：短时间内连续擦弹，充能倍率逐级上升，断了归零
   - 低速模式下擦弹范围更大、收益更高（顺带给低速流打底）
   - 擦弹有更明确的视觉和音效反馈
2. **符卡槽可以存多格**：存得越多，放出来越强（「憋大放小」）
3. **清屏掉资源**：符卡消掉的每颗敌弹变成「灵点」，吸收后本场战斗获得临时增益（擦弹范围、火力）
4. **三个通用升级（与闭环有化学反应）**
   - 擦弹时自动射出一发反击弹
   - 符卡结束后几秒内擦弹充能翻倍
   - 符卡槽越满伤害越高，放掉后归零
5. **奖励池改成 普通/稀有/史诗 三层**，现有 14 张符札的 Lv2、Lv3 逐步从数值改成机制

## 作者试玩 v0.7 后的问题（2026-11-16）—— 全部并入 9.5 步，用量预算不封顶

> 作者原话：「这一步是相当重要的，希望认真对待。」

### A. Boss 战强度严重不足
- 要求：弹幕「密集、密集、再密集」；弹幕也是演出，保持难度的同时要华丽
- 方案：
  - 每张符卡重做为「主弹幕 + 辅助弹幕 + 收尾爆发」三层，弹量提高到现在的 2～3 倍
  - 引入演出型弹种：激光（预警线 → 实体）、大玉、蝴蝶/刀/星/札等异形弹、会变向/加速/分裂的弹
  - 符卡宣言演出：背景变色、立绘 + 符卡名横幅、开场环形爆发
  - 难度靠「可读的规律」撑，不靠随机乱射；每张符卡有明确的躲法主题
  - ~~Boss 符卡加到 4～5 张~~ 作者更正：**符卡数量不用硬加，华丽程度才是最重要的**

### B. 事件、宝具、符札强化种类过少
- 目标数量（初定）：事件 6 → 25+，宝具 18 → 50+（普通/稀有/史诗三层），符札每张 Lv2/Lv3 改成机制分支（升级时二选一）
- 宝具围绕五个流派设计（擦弹、BOMB、使魔、低速、符卡爆发），每个流派至少 6 件核心 + 若干跨流派

### C. 道中战斗同质化
- 设计有机制特点的小怪，例如：
  - 使魔护盾型：本体无敌，先击破周围使魔
  - 分裂型：死后分裂成 2～3 个小的
  - 自爆型：冲向自机，死亡时炸出环形弹
  - 滞留型：留下不动的弹幕区域（考空间管理）
  - 狙击型：先显示瞄准线再射激光
  - 护卫型：给附近敌人加护甲
  - 逃跑型：不攻击但会跑，击破掉大量钱
  - 镜像型：模仿自机的横向移动
- 每章杂鱼组合不同，并按层数混搭

### D. 对话补充
- 精英战前加对话（每个精英一段）
- 击破敌人时少量台词：精英/Boss 被击破时一句，Boss 切换符卡时一句

### E. 符札、宝具的展示
- 做成可展开的「行囊」页面（地图界面一键打开）
- 每件物品有独立的物品立绘（大图标），点击查看完整效果、等级、羁绊

### F. 第四章解锁条件
- 现状问题：按流程打过去就拿到碎片，没有特点
- 方案（待作者确认，可组合）：
  1. **完美条件**：精英战无伤击破才掉碎片
  2. **隐藏路线**：每章地图里藏一个「隙间」节点，只有满足条件才会显现（例如本章擦弹达到某数量、或在事件中做出特定选择）
  3. **事件线索**：某些事件里有紫的式神留下的线索，选对选项才能拿到碎片
- 倾向：第 1 章用条件 1，第 2 章用条件 2，第 3 章用条件 3，三种玩法各不相同
